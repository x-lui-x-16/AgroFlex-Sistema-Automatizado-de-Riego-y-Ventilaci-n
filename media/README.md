# 🌿 Recursos visuales de AgroFlex
Esta carpeta reúne los recursos visuales utilizados para documentar el proyecto **AgroFlex: Sistema Automatizado de Riego y Ventilación**.

Aquí se almacenan las fotografías de los componentes electrónicos y las imágenes del prototipo, con el propósito de mantener organizado el material visual del repositorio y facilitar su integración en el archivo principal `README.md`.

## 📂 Organización de las imágenes
| Carpeta | Contenido |
|---|---|
| 🔌 [`Componentes`](componentes/) | Fotografías de los componentes electrónicos y dispositivos utilizados en el sistema. |
| 🤖 [`Prototipo`](prototipo/) | Fotografías del montaje, la instalación de los sensores, los sistemas de riego y ventilación y las pruebas de funcionamiento. |

## 🎯 Propósito

Mantener los recursos visuales de AgroFlex organizados y accesibles, facilitando la documentación del desarrollo, la presentación del prototipo y la consulta de sus componentes.
