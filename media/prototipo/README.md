# 🤖 Galería del prototipo AgroFlex
Esta carpeta reúne las fotografías del desarrollo físico de **AgroFlex**, desde el montaje de sus componentes hasta las pruebas de funcionamiento.

El objetivo es documentar visualmente la integración de los sensores, el microcontrolador, la pantalla LCD, el sistema de riego y el mecanismo de ventilación.

## 📸 Galería de imágenes
| Archivo | Descripción |
|---|---|

| `montaje-electronico.jpg` | 🔧 **Montaje electrónico:** presenta el controlador y las conexiones entre los componentes. |
| `sensor-suelo-instalado.jpg` | 💧 **Instalación del sensor de humedad:** muestra la ubicación del sensor en el sustrato. |
| `sensor-temperatura.jpg` | 🌡️ **Supervisión de la temperatura:** muestra la instalación del sensor DHT22 en el entorno de cultivo. |
| `sistema-riego.jpg` | 🚿 **Sistema de riego:** documenta la bomba y el mecanismo utilizado para conducir el agua hacia la planta. |
| `sistema-ventilacion.jpg` | 🌬️ **Sistema de ventilación:** muestra la instalación del ventilador y su integración en el prototipo. |
| `pantalla-lcd.jpg` | 📟 **Visualización de datos:** registra la información presentada en la pantalla LCD durante el funcionamiento. |
